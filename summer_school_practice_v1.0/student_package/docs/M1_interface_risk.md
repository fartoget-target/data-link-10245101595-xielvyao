1. **原始接口提供什么数据？**
   
   原始接口提供某一时刻航空器目标标识，呼号，来源国家，位置更新时间，最近联系时间，经纬度，气压高度，是否在地面，地速，航向，垂直速度，几何高度，位置来源

2. **为什么原始数据不是完整态势结果？**
   
   原始数据为定长数组，没有每个数据对应的数据名称，原始数据为某时刻的快照，而完整态势结果为每个目标的最新一条信息，无标识位和空值处理

3. **为什么发送方需要把内部状态封装成消息？**
   
   内部状态为一系列的数据，包含单位；封装成消息实现数据有序，易于切分和传输，同时封装成消息可以添加校验位以实现传输的准确性

4. **为什么接收方要检查长度、类型、校验和与保留位？**
   
   接收方检查长度以确保消息定长可按规定切分，检查类型以确认消息是正确要接收处理的消息，检查校验位以确保传输过程中无字段损坏，检查保留位以保证关键数据经纬度在传输过程中未被篡改，发送方未发送错误

5. **CSV 与 SQLite 分别承担什么角色？**
   
   CSV为中间交换格式和最终提交形式；
   
   SQLite为实现数据持久可追踪的记录，便于后续的查询

6. **至少列出三个工程风险，并说明影响与处理方式。**
   
   （1）字段缺失 ，影响：将非消息帧的0看作消息内容，污染消息原始数据，处理方式：使用validity_flags来判断0是否未有效物理量
   
   （2）消息损坏，影响：消息帧中的数据错误，处理方式：使用校验和确保消息传输正确
   
   （3）量化误差，影响：解码值与源码值出现误差，处理方式：误差控制在一个单位以内，与roundtrip_report.csv中比较原值与解码值
